# Spam Classifier CLI

A command-line based spam message classifier built using Machine Learning (Naive Bayes).

## Features
- Classifies messages as Spam or Ham
- Simple CLI interface
- Uses CountVectorizer and MultinomialNB

## Files
- main.py → Runs the CLI program
- model.py → Training and prediction logic
- data.csv → Dataset used for training

## How to Run
1. Open terminal
2. Run:
   python main.py

3. Choose option:
   1 → Check message
   2 → Exit

## Example
Input: free money  
Output: spam  

Input: hello bro  
Output: ham
